**Overview:**  
I built a virtualized network environment for testing and integrated AI tools to automate the evaluation of network configurations.

**What I did:**
- Designed and deployed various network topologies using `Mininet` on Linux (Ubuntu).
- Integrated AI Agents (using DeepSeek and LangGraph) to create an Auto-Grader System that validates the correctness of student-created network configurations.
- Handled routing, gateway setups, and processed real-time stream logs for the AI to analyze.

**Skills Gained:**  
Linux Administration, Software-Defined Networking (SDN), Python Scripting, API integration, and building automated workflows.
