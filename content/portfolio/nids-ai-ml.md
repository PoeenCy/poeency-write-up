**Overview:**  
This is my core academic research project, focusing on applying Machine Learning and Deep Learning to detect network anomalies and intrusions.

**What I did:**
- Extracted and processed network traffic features using the `NFStream` library.
- Trained and evaluated various models including LSTM, CNN, and LightGBM to classify network traffic (Benign vs. Attack).
- Explored and applied Knowledge Distillation techniques to compress the model, aiming to optimize performance for resource-constrained Edge/IoT devices.

**Skills Gained:**  
Network Data Processing, practical application of AI/ML, and model tuning/analysis.
